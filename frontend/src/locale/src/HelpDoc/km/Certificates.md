## ជំនួយអំពីវិញ្ញាបនបត្រ

### វិញ្ញាបនបត្រតាម HTTP

វិញ្ញាបនបត្រដែលផ្ទៀងផ្ទាត់តាម HTTP មានន័យថាម៉ាស៊ីនមេរបស់ Let's Encrypt នឹង
ព្យាយាមចូលទៅកាន់ដែនរបស់អ្នកតាម HTTP (មិនមែន HTTPS ទេ!) ហើយប្រសិនបើជោគជ័យ
ពួកគេនឹងចេញវិញ្ញាបនបត្រឱ្យអ្នក។

សម្រាប់វិធីសាស្ត្រនេះ អ្នកត្រូវតែបង្កើត _ម៉ាស៊ីន Proxy_ សម្រាប់ដែនរបស់អ្នក ដែលអាច
ចូលដំណើរការបានតាម HTTP និងចង្អុលមកកាន់ការដំឡើង Nginx នេះ។ បន្ទាប់ពីទទួលបាន
វិញ្ញាបនបត្រហើយ អ្នកអាចកែសម្រួល _ម៉ាស៊ីន Proxy_ ដើម្បីប្រើវិញ្ញាបនបត្រនេះសម្រាប់ការតភ្ជាប់
HTTPS ផងដែរ។ ទោះជាយ៉ាងណាក៏ដោយ _ម៉ាស៊ីន Proxy_ នៅតែត្រូវការការកំណត់រចនាសម្ព័ន្ធ
សម្រាប់ការចូលដំណើរការតាម HTTP ដើម្បីឱ្យវិញ្ញាបនបត្រអាចបន្តសុពលភាពបាន។

ដំណើរការនេះ _មិនគាំទ្រ_ ដែលប្រភេទ wildcard ទេ។

### វិញ្ញាបនបត្រតាម DNS

វិញ្ញាបនបត្រដែលផ្ទៀងផ្ទាត់តាម DNS តម្រូវឱ្យអ្នកប្រើកម្មវិធីជំនួយរបស់អ្នកផ្តល់សេវា DNS។
អ្នកផ្តល់សេវា DNS នេះនឹងត្រូវបានប្រើដើម្បីបង្កើតកំណត់ត្រាបណ្តោះអាសន្ននៅលើដែនរបស់អ្នក
បន្ទាប់មក Let's Encrypt នឹងសួររកកំណត់ត្រាទាំងនោះដើម្បីប្រាកដថាអ្នកជាម្ចាស់ ហើយប្រសិនបើ
ជោគជ័យ ពួកគេនឹងចេញវិញ្ញាបនបត្រឱ្យអ្នក។

អ្នកមិនចាំបាច់បង្កើត _ម៉ាស៊ីន Proxy_ មុននឹងស្នើសុំវិញ្ញាបនបត្រប្រភេទនេះទេ។ អ្នកក៏មិនចាំបាច់
កំណត់រចនាសម្ព័ន្ធ _ម៉ាស៊ីន Proxy_ របស់អ្នកសម្រាប់ការចូលដំណើរការតាម HTTP ដែរ។

ដំណើរការនេះ _គាំទ្រ_ ដែនប្រភេទ wildcard។

### វិញ្ញាបនបត្រផ្ទាល់ខ្លួន

ប្រើជម្រើសនេះដើម្បីបញ្ចូលវិញ្ញាបនបត្រ SSL ផ្ទាល់ខ្លួនរបស់អ្នក ដែលផ្តល់ដោយអាជ្ញាធរ
វិញ្ញាបនបត្រ (Certificate Authority) របស់អ្នកផ្ទាល់។
