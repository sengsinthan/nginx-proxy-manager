## តើបញ្ជីសិទ្ធិចូលប្រើគឺជាអ្វី?

បញ្ជីសិទ្ធិចូលប្រើផ្តល់នូវបញ្ជីខ្មៅ ឬបញ្ជីសនៃអាសយដ្ឋាន IP របស់អតិថិជនជាក់លាក់ ព្រមទាំងការផ្ទៀងផ្ទាត់សម្រាប់ម៉ាស៊ីន Proxy តាមរយៈ Basic HTTP Authentication។

អ្នកអាចកំណត់ច្បាប់អតិថិជន ឈ្មោះអ្នកប្រើប្រាស់ និងពាក្យសម្ងាត់ច្រើនសម្រាប់បញ្ជីសិទ្ធិចូលប្រើតែមួយ រួចយកវាទៅអនុវត្តលើ _ម៉ាស៊ីន Proxy_ មួយ ឬច្រើន។

វាមានប្រយោជន៍បំផុតសម្រាប់សេវាកម្មវេបដែលបញ្ជូនបន្ត ហើយមិនមានយន្តការផ្ទៀងផ្ទាត់ភ្ជាប់មកជាមួយ ឬនៅពេលអ្នកចង់ការពារពីអតិថិជនដែលមិនស្គាល់។
